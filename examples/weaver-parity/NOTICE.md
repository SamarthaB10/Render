# Weaver-class UI conformance fixture

This Widget is a Render-native visual acceptance fixture. It is inspired by the interaction and styling breadth demonstrated by Weaver's Noro shell, but uses original layout code and original SVG artwork.

`GeistPixel-Square.ttf` is reused under the SIL Open Font License included as `OFL.txt`. The named icons use Render's pinned Lucide catalog and its bundled Lucide license.

The fixture deliberately exercises the public SDK only: directional layout, asymmetric radii, ordered shadows, clipping, bundled fonts, deterministic icons, native hover/pressed/focus styles, persistent Slider state, tiled textures, gradients, and local images.
